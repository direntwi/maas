# Mobility as a Service (MaaS) Application
This repository contains the source code for a Mobility as a Service (MaaS) platform built using Django. The application is designed to allow users to request, book, and manage various transportation services. 
The project is currently in the extension phase, and several features are being added to improve functionality and user experience


# Features Under Development
1. Real-Time Tracking: Integration of GPS-based tracking for users to monitor ongoing trips.
2. Payment Integration: Adding support for multiple payment gateways to facilitate transactions.
3. Dynamic Pricing: Implementing dynamic pricing models based on demand and supply.
4. Route Optimization: Algorithms to optimize travel routes based on real-time traffic data.

# Installation
1. Clone this repository: ```git clone https://github.com/direntwi/maas.git```
2. Navigate into the project directory: ```cd maas```
3. Install dependencies: ```pip install -r requirements.txt```
5. Run migrations to set up the database: ```python manage.py migrate```
6. Start the development server: ```python manage.py runserver```

# Requirements
1. Python 3.x
2. Django 3.x or later
3. PostgreSQL or any other supported database
